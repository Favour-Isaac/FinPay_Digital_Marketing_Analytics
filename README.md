# FinPay_Digital_Marketing_Analytics
![image alt](https://github.com/Favour-Isaac/FinPay_Digital_Marketing_Analytics/blob/bb944a51fc64839f73b3c9681db232bdd95d8822/Finpay%20Digital%20logo.png)

## 🧠 Overview
This project evaluates FinPay Digital’s marketing performance using SQL-based analysis to generate actionable insights for improving customer acquisition and conversion efficiency. The analysis focuses on understanding campaign effectiveness, channel performance, and key marketing KPIs to support data-driven decision-making.

---

## 🎯 Analytical Objectives
This analysis aims to evaluate FinPay Digital’s marketing performance using SQL-based analysis to generate actionable insights for improving customer acquisition and conversion efficiency.

Specifically, the objectives are to:

- Evaluate campaign performance across different marketing channels to identify the most effective acquisition sources  
- Identify high-performing campaigns and creatives based on engagement and conversion metrics  
- Measure key performance indicators (KPIs) such as Click-Through Rate (CTR), Customer Acquisition Cost (CAC), Return on Investment (ROI), and Conversion Rate  
- Analyze campaign-level engagement patterns to understand performance differences across campaigns and channels  

---

## 🛠️ Tools Used
- Microsoft SQL Server – Data extraction, transformation, and analysis    
- Excel – Data cleaning and validation  

---

## 📊 Key Analysis Areas

### 1. Channel Acquisition Effectiveness
Analyzed which marketing channels drive the highest user and merchant acquisition and how engagement varies across channels.

### 2. Campaign Performance Analysis
Evaluated campaign effectiveness using impressions, clicks, and conversions to identify top and underperforming campaigns.

### 3. Customer Journey Conversion Efficiency
Measured funnel performance from impressions → clicks → conversions to identify drop-off points and inefficiencies in the customer journey.

---

## 📈 Key Insights
- Campaign performance varies significantly across channels and strategies  
- High impressions do not always translate into high conversions  
- A small number of campaigns drive the majority of conversions  
- Some campaigns show strong reach but weak conversion efficiency  
- Conversion rate is a more reliable performance metric than impressions alone  

---

## 📌 Conclusion
The analysis highlights inefficiencies in campaign performance and emphasizes the need to optimize targeting, messaging, and budget allocation. Improving conversion efficiency across underperforming campaigns will significantly enhance overall marketing ROI.
